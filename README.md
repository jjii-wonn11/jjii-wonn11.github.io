# GitHub Pages 포트폴리오 적용 방법

이 폴더의 내용은 `jjii-wonn11.github.io` 저장소 최상단에 그대로 올리면 됩니다.

## 파일 구조

```text
jjii-wonn11.github.io/
├── index.html
├── styles.css
├── script.js
├── projects/
│   ├── weather.html
│   ├── churn.html
│   └── loan.html
├── assets/
│   ├── images/
│   └── documents/
└── downloads/
```

## 적용 순서

1. ZIP 파일의 압축을 풉니다.
2. 현재 저장소의 `index.html`을 새 `index.html`로 교체합니다.
3. `styles.css`, `script.js`, `projects`, `assets`, `downloads`를 저장소 최상단에 업로드합니다.
4. 모든 파일을 선택해 커밋합니다.
5. 배포 후 `https://jjii-wonn11.github.io/`에서 프로젝트 카드와 자료 다운로드 링크를 확인합니다.

`프로젝트 자세히 보기`는 각각의 HTML 파일로 연결되어 상세 페이지 최상단에서 시작합니다.
